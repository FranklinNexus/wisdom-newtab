A quieter start to every tab.

Install the browser extension on desktop and Edge Android, or use the companion app as a mobile fallback.

Install desktop extension Open mobile app

Chrome

Select Add to Chrome, confirm the installation, then open a new tab.

Microsoft Edge

Allow extensions from other stores if prompted. Edge may pause the extension because it replaces the New Tab page; select Turn on once to confirm.

This is a browser settings confirmation, not a malware warning.

Phone & tablet

Edge on Android supports a native New Tab extension. Its Microsoft Edge Add-ons edition is being prepared for store review; after installation, choose Always start with a fresh new tab in Edge to cover cold launches too. Microsoft's public mobile extension collection is curated separately.

For Chrome on Android and browsers on iPhone, open the companion app and choose Install app or Add to Home screen.
